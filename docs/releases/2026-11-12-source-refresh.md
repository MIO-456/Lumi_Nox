# 2026-11-12 公开模块更新

这次分批移植主工程中可独立使用的改进，继续保留公开版的包布局、占位配置和演示入口。它不是完整直播工程的镜像。

## 第一批：核心与记忆

- 事件请求在独立守护线程中执行订阅回调，等待响应的超时包含慢回调执行时间；请求结束后拒绝迟到响应。普通 `publish()` 仍同步执行。超时不会强制终止回调；有外部副作用的回调应检查 `event.is_active`，并自行处理取消。
- 语音仲裁可以按 `output_id` 取消，旧任务不能取消新任务的发声。
- 观众名称增加 Unicode 规范化和进房点名去重，保留零点名上限。
- 记忆事实通过事务更新，保护人工修正，拒绝旧消息重放覆盖新事实；称呼别名统一到同一冲突域。
- 提取输入包含同一观众、同一会话的相邻消息。只有 `target` 是提取来源，`context` 用于理解；公开提示词已补充此协议。
- 收尾接口接收明确的 session 列表；检索不再把未经提炼的原始发言作为长期记忆兜底注入。

验证：21 项离线单元测试、源码编译、公开依赖与内容审查通过。数据库测试使用临时数据，模型调用使用替身；真实模型提取质量未在本次验证。
